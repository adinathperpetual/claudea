CONTRACT NOTE EXTRACTOR — Windows desktop app
==============================================

HOW TO START
  Double-click "Contract Note Extractor.exe".
  The tool opens in its own window (Microsoft Edge or Google Chrome app window).
  No installation and no internet connection are needed.

FIRST RUN
  Windows may show "Windows protected your PC" because the program is not
  digitally signed. Click "More info" -> "Run anyway". This is asked only once.

  Sign in with username: admin   password: admin
  You will be asked to choose a new password straight away.

WHERE YOUR DATA IS KEPT
  Your client master, users, template and uploaded PDFs are saved on this
  computer inside the browser profile (Edge or Chrome) used by the app window.
  Nothing is uploaded anywhere — all processing happens on this computer.
  Keep using the same browser so the saved data stays available.

CLOSING
  Just close the window. The program stops by itself a few minutes later.
  Starting it again while it is still running simply opens a new window.

MOVING / UPDATING
  The .exe can be copied to any folder or PC. To update, replace the .exe with
  the new version — your saved data is kept.

REQUIREMENTS
  Windows 10 or 11 (64-bit) with Microsoft Edge (built in) or Google Chrome.
  The program only listens on this computer (127.0.0.1, port 47821); it is not
  reachable from the network.
