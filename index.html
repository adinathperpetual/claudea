One file, three columns: Client Name, Trading Account and Password. Headers are recommended (e.g. Client Name | Trading Account | Password); extra password columns (Password 1, Password 2…) or the same name repeated on several rows are all collected.
• Password: the client name is read from the end of each PDF's file name (the part after the last "_", e.g. ..._gayatri jain.pdf) and every password listed for that name is tried; if none open the file it falls back to per‑file entry.
• Trading account: matched to the client name printed in the contract note, allowing for missing middle names and reversed name order.
Importing a new file replaces the saved master. Saved in this browser only — nothing is uploaded.
