CONTRACT NOTE EXTRACTOR  (installed with ContractNoteExtractor-Setup.exe)
=========================================================================

FIRST TIME (Admin, once per PC)
  1. Run ContractNoteExtractor-Setup.exe and click Next > Install > Finish.
     It installs the tool, makes Start-menu and desktop shortcuts and opens it.
  2. On the first start
     - It asks for the Finesse User ID, Password and PAN, creates the keys,
       and tests the login. Answer Y to the test.
     - Then the tool opens in the browser.
  3. The access tokens and the key backup are saved in data\ACCESS_TOKENS.txt
     (Start menu > Contract Note Extractor > Access tokens and key backup).
     Keep that file private and keep a copy of the key somewhere safe.

EVERY DAY
  Double-click "Contract Note Extractor" on the desktop and keep the black
  window open while you work. Closing it stops the tool.

START MENU > CONTRACT NOTE EXTRACTOR
  Change Finesse login (setup)    change the Finesse login / settings
  Test Finesse login              check the Finesse login
  Sync clients from Finesse now   fetch the client list from Finesse now

NOTES
  * Reading Finesse uses Microsoft Edge (or Google Chrome) already on the PC.
  * Windows may say "Windows protected your PC" the first time because the
    installer is not signed: click "More info" then "Run anyway".
  * To update, run the newer ContractNoteExtractor-Setup.exe. Your settings
    (.env) and data (data\) are kept, also when you uninstall.
